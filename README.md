# 政策雷达 · 第一手信息源版

只盯**发布主体本身**，不看转载和媒体解读。国家盯部委与国务院，深圳盯各局与各区官网。

打开 `out\index.html` 就是日历：**每天格子里既显示法定节假日，也显示当天发布的政策**，
像手机自带日历那样一眼看完。`out\policies.ics` 可导入手机日历。

---

## 一、什么算「第一手」

| 层级 | 谁发的 | 是否第一手 | 说明 |
|---|---|---|---|
| 法律 | 全国人大及其常委会 | ✅ | 经国家法律法规数据库 / 中国政府网发布 |
| 行政法规 | 国务院 | ✅ | 国务院令、国发、国办发 |
| 部门规章与规范性文件 | 各部委（人社部、住建部、自然资源部…） | ✅ | **本项目的重点**，很多政策只在这里发，不上新闻 |
| 地方性法规 / 政府规章 | 广东省人大、深圳市政府 | ✅ | 深圳「政策法规库」收录 |
| 部门规范性文件 | 深圳市各局 | ✅ | 各局官网 / 政府信息公开平台 |
| 媒体报道、解读文章 | 人民网、新闻网 | ❌ 二手 | 只做信号，不做依据，本项目**已剔除** |

判断标准很简单：**文件号（如「深府〔2026〕63号」「自然资发〔2023〕193号」）的出具单位，就是一手源。** 其余都是转述。

## 三、现成项目能不能直接用？

查了一圈，结论是**分层的**：

| 层 | 现成方案 | 能否直接用 |
|---|---|---|
| 全国政务站地址清单 | [`gov-site-list`](https://github.com/baiyigali/gov-site-list)（PyPI 包，含 40+ 部委的「政策法规/通知公告」栏目精确 URL） | ✅ **直接用了它的清单**来定国家级源，省了自己一个个找 |
| 全国站点轮询 + 增量 | [`gov_monitor`](https://github.com/baiyigali/gov_monitor) | ⚠️ 只到「发现新通知」，没有分类、没有 AI、没有日历 |
| 部委 RSS | RSSHub `/gov/*` 路由（如 `/gov/csrc/...`） | ⚠️ 只覆盖证监会等少数部门，人社部/住建部/自然资源部没有路由 |
| 法律法规全文 | [`lawtext/laws`](https://github.com/lawtext/laws)、国家法律法规数据库 `flk.npc.gov.cn` | ✅ 法律条文底库可用，但它是**存量库**，不做增量发布监控 |
| 深圳各局 | **无现成项目** | ❌ 必须自建。深圳各局官网全是 JS 渲染 + 部分反爬，没有公开 RSS |

**所以结论**：国家层面的「源地址」有现成清单可用（已采纳），但「深圳各局 + 统一抓取 + 日历 + AI」这一层没有现成项目，本项目自己做了。

部委直连的实测结果（都试过了，如实记录）：

| 部委 | 直连 | 解法 |
|---|---|---|
| 人社部 `mohrss.gov.cn` | ❌ JS 挑战页（EO_Bot_Ssid 动态 cookie） | ✅ **无头 Edge 渲染后取 DOM，已接入** |
| 住建部 `mohurd.gov.cn` | ❌ 政策栏目 JS 异步加载 | ✅ **无头 Edge + 标题过滤，已接入** |
| 司法部 `moj.gov.cn` | ❌ Angular 渲染，链接是 `javascript:;`，无真实 URL | ❌ 暂不接（渲染出来也没有可点的原文链接） |
| 医保局 `nhsa.gov.cn` | ✅ 服务端渲染 | 已接入 |
| 自然资源部 `mnr.gov.cn` | ✅ 服务端渲染 | 已接入 |

人社部是靠 `msedge.exe --headless --dump-dom` 拿下挑战页之后拿到的，
现在能抓到「企业年金个人账户转移接续规程」「失业保险支持企业稳岗」这类社保文件。

## 四、怎么让它自己跑、手机直接看

**不用开着电脑。** 三种方式，详见 [deploy.md](deploy.md)：

| 方式 | 要什么 | 手机怎么看 | 多久能好 |
|---|---|---|---|
| **A. GitHub Actions + Pages** | 一个 GitHub 账号 | 浏览器打开网址 / 订阅系统日历 | 5 分钟，免费 |
| B. 国内云函数（腾讯 SCF / 阿里 FC） | 实名 + 对象存储 | 同上 | 20 分钟，免费额度够 |
| C. NAS / 软路由 / 旧手机常驻 | 家里有个一直开着的设备 | 同上 + 内网穿透 | 半小时起 |

A 是最省事的：`.github/workflows/radar.yml` 已经写好，每小时跑两轮，
跑完把 `out/` 发布到 GitHub Pages，手机打开
`https://<用户名>.github.io/<仓库名>/` 就是最新日历，
`.../policies.ics` 可以直接被 iPhone/Android 系统日历订阅。

> GitHub 的机器在境外，个别政务站可能限流。跑完看 Actions 日志里每个源的成败，
> 如果深圳那批全失败，换 B 路线（国内云函数）即可，代码不用改。

**推送**（比刷网页更快）：`config.json` 里配 `notify`，新的 ★4+ 政策直接推手机。

```json
{ "notify": {
    "wecom": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx",
    "bark": "https://api.day.app/你的key",
    "site_url": "https://<用户名>.github.io/<仓库名>/" } }
```

支持企业微信 / 钉钉 / 飞书 / Telegram / Bark，配哪个发哪个。测通道：`python notify.py`。
GitHub Actions 上可以把整段配置塞进仓库 Secret `CONFIG_JSON`，不必提交到仓库。

### 本地手动跑

```bat
打开日历.bat          :: 抓取 + 生成 + 打开日历（日常点这个）
立即抓取.bat          :: 只抓取，看日志
install_schedule.bat  :: 装 Windows 计划任务，每 30 分钟静默巡检
```

命令行：`python radar.py sync` / `render` / `show`，加 `--no-ai` 只用规则引擎。
单独重建节假日：`python build_holidays.py`。测推送：`python notify.py`。

只依赖 Python 标准库 + `curl` + 一个 Chromium 内核浏览器（本地用 Edge，云端用 Chrome），
不用 pip 装东西。

## 五、AI 分析

默认规则引擎（离线、不花钱）：分类、重要度、领域/区域标签、**截止日期抽取**、影响判断、建议动作。

要更细的逐条精读，建 `config.json`：

```json
{ "api_key": "sk-xxx", "base_url": "https://api.deepseek.com/v1", "model": "deepseek-chat" }
```

或设 `DEEPSEEK_API_KEY` 环境变量。失败自动回落规则引擎，不影响抓取。

当前实测：505 条里识别出 18 条带明确截止日期，最近的是
`2026-11-16`（南山区产业专项资金第六批申报）、`2026-11-20`（APEC 期间外地车限行）、
`2026-11-23`（科创局深港澳 C 类项目申请）、`2026-12-31`（居民医保集中参保缴费）。

## 六、降噪规则（重要）

深圳各局的列表里混着大量非政策内容，已按栏目名 + 标题双重过滤：

- **按栏目剔除**：政府采购、仲裁公告、工作动态、财政预决算、三公经费、数据快递、政务服务…
- **按标题剔除**：带「？」的问答（"……是多少"）、询价/招标/中标、采购项目
- **降权**：`建设工程规划许可证/总平面图/宗地` 这类单项目公示 → 判为「项目公示」★2，不占重点位
- **只留中文**：税务局「走出去」指南里的俄语/英语问答已剔除
- **标题去重**：同一文件被多局转发只留一条

面板上「只看重点 ★4+」一键过滤。

## 八、还没覆盖的

1. **司法部官网**：页面能渲染出来，但每条政策的链接是 Angular 的 `javascript:;`，
   没有可点原文地址，接了也没意义。暂时放弃。
2. **宝安区本级**：`www.baoan.gov.cn` 首页不给站点 ID，枚举号段也没命中，
   目前只有宝安下属街道与教育局。需要从区站页面里再找。
3. **国家法律法规数据库全文**：`flk.npc.gov.cn` 改版后接口变了，
   法律条文级检索要重新对接（法律本身已通过国务院渠道覆盖）。
4. **公积金**：`gjj.sz.gov.cn` 域名已无解析；深圳公积金政策由住建局站点覆盖，
   国家层面由住建部《住房公积金管理条例》覆盖。
